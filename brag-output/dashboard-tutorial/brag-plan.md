# Balbird Dashboard BRAG Plan

## 9-Question Rubric Answers

1. **What is the app?**
   Balbird is a cross-border manufacturing execution partner platform for mobility components, providing a role-based dashboard for manufacturers, OEMs, and strategic partners to coordinate production workflows, manage requirements, track orders, and ensure full manufacturing traceability.

2. **What is the funniest or most impressive claim?**
   "Not a Broker. Not a Marketplace. An Execution Partner." - this distinctive positioning statement stands out in the manufacturing space.

3. **What is the visual hook?**
   The dashboard's clean B2B SaaS design with horizontal navigation tabs, role-based stat cards with icons and metrics, and the blue accent color (#2563eb) against white backgrounds. The cards showing progress indicators and status badges are visually strong.

4. **What should be shown from the actual UI?**
   The dashboard overview page showing role-based stats cards (Active Requirements, Supplier Matches, Active Orders, On-Time Delivery), the horizontal navigation, and key sections like Requirements, Suppliers, and Orders with their actual data and interfaces.

5. **What is the shortest satisfying video?**
   20-25 seconds works well to show: Dashboard entry → Navigation highlights → Requirements section → Suppliers section → Orders section → Return to dashboard.

6. **What tone fits best?**
   - **Tone preset:** polished
   - **Creative direction:** premium B2B SaaS product tutorial - clean, professional, trustworthy, modern manufacturing technology

7. **What should the audio feel like?**
   Warm corporate bed with subtle tech accents - professional background music that supports the clean UI-focused composition without being distracting. SFX should match UI interactions (clicks, transitions).

8. **What should the share caption say?**
   "See how Balbird's dashboard streamlines manufacturing execution with role-based workflows, requirement management, and supplier coordination."

9. **What's the user flow worth showing?**
   Dashboard overview → Navigate to Requirements → View active requirements → Navigate to Suppliers → See supplier management → Navigate to Orders → View production orders → Return to dashboard overview.

## Storyboard (20-25 seconds)

### Scene 1: Dashboard Entry (0-3s)
- **Visual:** Clean fade-in of the Balbird dashboard overview
- **Action:** Show the role-based dashboard with OEM view (8 Active Requirements, 12 Supplier Matches, 15 Active Orders, 94% On-Time Delivery)
- **Text:** "Dashboard" 
- **Camera:** Subtle zoom in on the stat cards
- **Duration:** 3s

### Scene 2: Navigation Highlight (3-6s)
- **Visual:** Horizontal navigation tabs with cursor movement
- **Action:** Cursor moves across the navigation highlighting "Overview", "Requirements", "Supplier Matching", "Active Orders", "Documents"
- **Text:** "Navigate your workspace"
- **Camera:** Smooth pan across navigation bar
- **Duration:** 3s

### Scene 3: Requirements Section (6-10s)
- **Visual:** Click on "Requirements" tab, transition to Requirements page
- **Action:** Show the Requirements page with status cards (Active: 12, Pending Review: 5, Completed: 28) and the overview statistics
- **Text:** "Requirements"
- **Camera:** Subtle zoom on the Active requirements card
- **Duration:** 4s

### Scene 4: Suppliers Section (10-14s)
- **Visual:** Click on "Suppliers" in navigation, transition to Suppliers page
- **Action:** Show Supplier Management page with supplier stats (24 Active Suppliers, 4.6 Avg Rating, 94% On-Time Delivery) and top performing suppliers list
- **Text:** "Suppliers"
- **Camera:** Pan down to show the supplier list with ratings and performance metrics
- **Duration:** 4s

### Scene 5: Orders Section (14-18s)
- **Visual:** Click on "Orders" in navigation, transition to Orders page
- **Action:** Show Production Orders page with order stats (12 Active Orders, 4 New Orders, 8 Ready for Delivery) and active production orders with progress bars
- **Text:** "Orders"
- **Camera:** Focus on an order card with progress bar showing production status
- **Duration:** 4s

### Scene 6: Return to Dashboard (18-21s)
- **Visual:** Click on "Overview" to return to main dashboard
- **Action:** Smooth transition back to dashboard overview showing the complete workspace
- **Text:** "Balbird Dashboard"
- **Camera:** Wide shot of the full dashboard interface
- **Duration:** 3s

### Scene 7: Closing Frame (21-25s)
- **Visual:** Clean branded closing with Balbird logo and tagline
- **Action:** Fade in Balbird logo with "Not a Broker. Not a Marketplace. An Execution Partner."
- **Text:** "Balbird Industries"
- **Camera:** Static centered composition
- **Duration:** 4s

## Pacing Notes

- Keep each scene focused on one key message
- Ensure text is readable (hold labels ~0.8s settled)
- Make clicks obvious with visual feedback
- Highlight important UI areas with subtle emphasis
- Maintain professional, trustworthy feel throughout
- No unnecessary visual effects or stock footage
